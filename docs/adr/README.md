# Registro de decisiones (ADR)

Acá van las decisiones **transversales a todos los lenguajes**: valen para la especificación y para cada SDK de la
organización. Las decisiones propias de un lenguaje van en el repositorio de ese SDK.

Una decisión aceptada no se edita para cambiarla: se escribe una ADR nueva que la reemplaza y se marca la anterior
como "Reemplazada por NNNN".

| N.º | Decisión | Estado |
|---|---|---|
| [0001](0001-transportar-y-verificar-no-calcular.md) | El SDK transporta y verifica, no calcula | Aceptada |
| [0002](0002-exigir-exactamente-lo-que-sifen-documenta.md) | Exigir exactamente lo que SIFEN documenta | Aceptada |
| [0003](0003-especificacion-como-datos.md) | Especificación como datos y batería de conformidad compartida | Aceptada |
| [0004](0004-vigencia-por-fecha-y-ambiente.md) | Reglas activadas por fecha y por ambiente | Aceptada |
| [0005](0005-precedencia-entre-fuentes.md) | Precedencia entre Manual, Notas Técnicas y XSD | Aceptada |
| [0006](0006-xsd-incluidos-con-procedencia.md) | XSD de la DNIT incluidos con procedencia y hash | Aceptada |
| [0007](0007-cobertura-de-documentos-y-eventos.md) | Cobertura de tipos de documento y eventos | Aceptada |

Para proponer una decisión nueva, copiá la [plantilla](0000-plantilla.md) con el número siguiente.
